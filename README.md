# STL Slicer — нарезка модели на листы для склейки скульптуры

Инструмент режет 3D-модель (STL) на плоские слои заданной толщины, **с промежутками между слоями**
(их потом заполняют), добавляет **отверстия под направляющие стержни**, чтобы слои не съезжали,
раскладывает детали по листам материала и выдаёт файлы для резки:

- **SVG** (мм, красный = рез, синий = гравировка) — для лазера / LightBurn / Inkscape;
- **DXF** (R12, слои `CUT` и `ENGRAVE`) — для CAM и CAD;
- **G-code** — для лазера на GRBL (M3/M4 + S) или для фрезера (проходы по Z, компенсация фрезы).

Это не 3D-печать: результат — набор плоских деталей (фанера, МДФ, пенопласт, картон, акрил),
которые нанизываются на стержни с проставками и склеиваются в большую скульптуру.

## Быстрый старт

```bash
npm install
npm run dev        # веб-интерфейс на http://localhost:5173
npm run build      # статическая сборка в dist/ (можно выложить на любой хостинг)
npm test           # тесты ядра
```

### Веб-интерфейс

1. **Открыть STL** (или перетащить файл в окно; есть кнопка «Пример (утка)»).
2. **Модель** — задайте высоту скульптуры в мм (или масштаб) и поверните модель так, чтобы её верх
   смотрел вверх: слои режутся перпендикулярно оси Z.
3. **Слои** — толщина листа, зазор между листами, режим контура (см. ниже).
4. **Направляющие** — кнопка «Авто» расставит стержни сама; на вкладке **«Слой / направляющие»**
   можно кликом добавить стержень, перетащить его, удалить правой кнопкой (или Delete).
   В таблице можно точно задать X, Y, диаметр и диапазон по высоте «Z от / Z до».
   На слое видны контуры соседних слоёв (ниже — серый, выше — синий).
5. **Раскрой** — предпросмотр листов; каждый лист можно скачать отдельно (SVG/DXF/G-code).
6. **Экспорт → Скачать ZIP** — все файлы + `report.txt` (список стержней с длинами, слои,
   предупреждения) + `project.json` (настройки и направляющие, можно загрузить обратно).

Внизу всегда видны предупреждения: деталь без направляющей, стержень выходит за край, тонкая стенка
и т.п. Клик по предупреждению открывает нужный слой.

### Командная строка

```bash
node cli.js model.stl -o out --height 600 -t 10 -g 5 --auto-guides 2 --guide-d 8 \
  -f svg,dxf,gcode --sheet 1200x800 --kerf 0.2

node cli.js model.stl -p project.json -f gcode --machine router --kerf 6   # настройки из веб-интерфейса
node cli.js --help
```

## Как это устроено

- Листы идут с шагом `толщина + зазор`, первый начинается с `Смещение первого слоя`.
- **Контур листа**:
  - `по середине` — сечение посередине толщины листа (по умолчанию);
  - `внешний` — объединение нескольких сечений по толщине листа: деталь не меньше модели,
    удобно, если потом всё шлифуется «в ноль»;
  - `внутренний` — пересечение сечений: деталь нигде не выступает за модель;
  - `по низу` / `по верху`.
- **Направляющие** — вертикальные стержни (шпилька, дюбель, трубка). В каждом листе, через который
  проходит стержень, вырезается отверстие. Между листами на стержень надеваются проставки
  высотой с зазор (или зазор фиксируется гайками на шпильке). Авторасстановка разбивает стопку на
  группы слоёв с общей площадью, соседние группы делят один лист, чтобы вся стопка была связана;
  отдельные «ветки» модели получают свои стержни.
- **Гравировка** — номер детали (`12`, или `12-2` если в слое несколько деталей) и контур
  следующего слоя — по нему удобно ориентироваться при сборке. Гравировка — на верхней стороне.
- Файлы «по слою» (`layers/`) имеют общий ноль координат, поэтому их можно наложить друг на друга;
  файлы раскроя (`sheets/`) — детали, разложенные по листам заданного размера.
- **Компенсация реза** (`kerf`) смещает траекторию наружу на половину ширины луча/фрезы
  (для фрезера укажите диаметр фрезы). Отверстия режутся раньше внешнего контура.
- G-code: ноль — левый нижний угол листа; для фрезера Z0 — верх материала, глубина по умолчанию
  `толщина + 0.3 мм`.

## Структура

```
src/core/       ядро (работает и в браузере, и в Node)
  stl.js        чтение STL (бинарный и ASCII)
  mesh.js       поворот/масштаб/установка на стол, сварка вершин
  slice.js      сечение плоскостью → замкнутые ориентированные контуры
  geom.js       булевы операции и офсеты (Clipper)
  layers.js     листы, направляющие, авторасстановка, проверки
  drawing.js    детали → чертежи, раскрой, разметка
  nest.js       раскладка деталей по листам
  font.js       однолинейный шрифт для номеров
  export/       svg.js, dxf.js, gcode.js
  project.js    общий конвейер для UI и CLI
src/ui/         веб-интерфейс (three.js, Vite)
cli.js          командная строка
test/           тесты (node --test)
```
